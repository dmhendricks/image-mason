Image Mason

Version {{version}}

Send a JPEG, PNG, WebP, AVIF or JPEG XL and get a smaller one back, in the same format or another. Lossy results are held to a perceptual quality score, so a preset describes how the image looks, not an encoder setting.

Optimize

curl -sS --data-binary @photo.jpg -o photo.min.jpg \
  {{origin}}/api/v1/optimize
curl -sS -G --data-urlencode "url=https://example.com/photo.jpg" \
  -o photo.min.jpg {{origin}}/api/v1/optimize

The body is the raw image, or url names one to download. The response is the optimized file, with its statistics in X-Image-Mason-* headers. When the server has an API key, send it in the X-Api-Key header.

Convert

curl -sS --data-binary @photo.jpg -o photo.webp \
  "{{origin}}/api/v1/convert?format=webp"

format is jpeg, png, webp, avif or jxl. The result is optimized with the same quality presets and parameters as optimize.

Resize

curl -sS --data-binary @photo.jpg -o thumb.webp \
  "{{origin}}/api/v1/resize?width=400&height=400&fit=cover&format=webp"

fit is contain (default), cover (fill the box and crop) or fill (stretch). Images are only enlarged with upscale=true.

Crop

curl -sS --data-binary @photo.jpg -o square.jpg \
  "{{origin}}/api/v1/crop?rect=80,0,480,480"

rect is left,top,width,height in pixels, as the image is displayed. Add width, height or format to resize or convert the cropped area in the same call.

Store

curl -sS --data-binary @photo.jpg \
  "{{origin}}/api/v1/optimize?output=json"

output=json stores the result and returns its URL and statistics as JSON. POST /api/v1/upload stores an image unchanged; pass the name at the end of its URL as source to run more jobs on it without sending it again. Stored images are served for {{ttlMinutes}} minutes; anyone with the URL can fetch them until then.

Quality presets

PresetResult
losslessIdentical pixels; only the encoding is optimized
high (default)No visible difference in place at 1:1
mediumNo visible difference side by side at 1:1
lowBarely visible difference side by side

minScore sets a custom quality floor (SSIMULACRA2, 0–100), maxWidth downscales wider images (or width, height and fit resize to a box, as with resize), format converts while optimizing, and preferJpeg=true returns a JPEG when a PNG is really a photo.
